# Third-party components

This product uses the open-source speech model and `omnivoice` Python package by k2-fsa
(https://github.com/k2-fsa/OmniVoice), licensed under Apache-2.0.

Gradio (Apache-2.0) provides the web interface.

At runtime the studio engine may be loaded from the public AS VOICE STUDIO V3 project structure
(https://github.com/AS-STUDIO-PRO/AS-VOICE-STUDIO-V3). GHX STUDIO provides branding, support contact,
and paid access control for this distribution.
